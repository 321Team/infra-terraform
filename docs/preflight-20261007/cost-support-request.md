## 회신 접수 및 계산

[입력표](cost-inputs.json)의 null은 미확인이다. 회신자·원본 링크/파일·조회 시각을 기록하며 Gross, credit 차감 Net, 지원 잔액을 서로 대체하지 않는다. ROSA 구독 조건을 직접 수락하지 않는다.

`예상 총 Gross = 현재 Gross A + 미반영 U + 남은 운영비 C_run + 정리·잔존비 C_cleanup`.
`계획상 여유 = 400 - (A + U + C_run + C_cleanup)`; `중단선 여유 = 450 - 같은 합계`.
기간·통화·요금 기준이 같을 때만 비교한다. 어느 항목이든 미확인이면 합계/GO는 미판정이다. 비용 내역은 worker EC2, ROSA service/HCP, Relay, EBS, public IPv4/EIP, NAT, LB, DNS/endpoint, 전송, backup/잔존/세금으로 분리한다. 실제 미사용 항목은 소유자 근거가 있을 때만 0으로 입력한다.

가동시간은 [운영창](operating-teardown-plan.md)의 비교 시나리오를 사용한다. worker 3대 시간과 cluster 시간을 혼동하거나 모든 항목에 같은 시간을 곱하지 않는다. 시간단가·수량별 단위와 공식 견적 시각/URL을 #35/#38 담당 입력으로 받는다. 공시 요금만으로 교육장 지원 가능 여부를 판정하지 않는다.
